`audios.json` mapeia cada id de nó de conteúdo a um clipe. Para reproduzir uma página, colete os `data-id` no documento renderizado, procure-os em ordem e reproduza os clipes resultantes em sequência.

## Torne a reprodução resiliente

Mostre o controle apenas quando `features.readAloud` for `true` **e** a página atual tiver clipes. A flag informa se o livro possui narração, não é uma preferência do leitor.

Com Leitura Fácil ativa, prefira um clipe `_easy_read` quando existir e, caso contrário, use o clipe normal. Mantenha a reprodução sequencial mesmo sem tempos por palavra.

## Destaque de palavras

O contrato público V1 não define dados de tempo por palavra. Para a narração ADT, mantenha a sincronização no nível do nó, exceto quando o pacote documentar uma extensão compatível.

No EPUB, verifique primeiro `media-overlay` no `<item>` do documento de conteúdo no manifesto OPF. Quando existir, use os Media Overlays SMIL nativos do EPUB, em vez de reconstruir a sincronização a partir de sidecars.

<Callout type="info" title="Trate a sincronização como aprimoramento progressivo">
A narração continua funcionando sem tempos por palavra. Não bloqueie a reprodução quando o livro tiver clipes, mas não tiver Media Overlays.
</Callout>
