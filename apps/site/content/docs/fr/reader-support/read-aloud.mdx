`audios.json` associe chaque id de nœud de contenu à un extrait. Pour lire une page, recueillez les `data-id` du document rendu, recherchez-les dans l’ordre et jouez les extraits obtenus en séquence.

## Rendez la lecture résiliente

N’affichez la commande que lorsque `features.readAloud` est `true` **et** que la page actuelle possède des extraits. L’indicateur dit que le livre a des données de narration, ce n’est pas une préférence du lecteur.

Avec la Lecture facile active, préférez un extrait `_easy_read` s’il existe, puis l’extrait normal. Gardez la lecture séquentielle même sans minutage par mot.

## Surlignage des mots

Le contrat public V1 ne définit pas de données de minutage par mot. Pour la narration ADT, gardez une synchronisation au niveau du nœud, sauf si le package documente une extension compatible.

Dans un EPUB, vérifiez d’abord `media-overlay` sur le `<item>` du document de contenu dans le manifeste OPF. Lorsqu’il existe, utilisez les Media Overlays SMIL natifs d’EPUB plutôt que de reconstruire la synchronisation depuis des sidecars.

<Callout type="info" title="Traitez la synchronisation comme une amélioration progressive">
La narration fonctionne sans minutage par mot. Ne bloquez pas la lecture lorsque le livre a des extraits mais pas de Media Overlays.
</Callout>
