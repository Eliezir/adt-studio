ADT Studio turns any PDF into an accessible, fully structured book. It extracts
content, runs it through inspectable LLM pipelines, and packages formatted
output — without hiding what happens in between. This doc is built to get you
from zero to a finished book fast, then help you operate it confidently.

## Why ADT Studio Exists

Accessible book production is slow, manual, and easy to get wrong. Content gets
re-keyed, structure gets lost, and the steps that turn a PDF into something a
screen reader can navigate are scattered across tools that don't talk to each
other.

ADT Studio brings the whole process into one place, built around a few
non-negotiable ideas: every book lives in a single shareable directory, nothing
is ever overwritten, and every LLM call is cached and inspectable. Reruns are
fast, results are reproducible, and there are no black boxes.

## Transparency by Default

Every prompt, every response, and every cost is something you can open and read.
When a result looks wrong, you can see exactly which call produced it, change
the inputs, and rerun — only the work that actually changed is recomputed.
